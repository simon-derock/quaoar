# Security

If you find a vulnerability in Quaoar, please report it privately through GitHub:
**Security → Report a vulnerability** on this repository. Please do not open a public issue.

What helps us act fast:
- the affected command, endpoint or file
- steps to reproduce
- what an attacker could do with it

Scope notes:
- The public demo API serves recorded fixtures only and holds no API keys.
- Keys for SerpApi and Cohere live only in a local `.env` that is never committed.
