# Control prospectuses: does Quaoar stay quiet on ordinary companies? (2026-10-09)

## Rule, written before any control was scanned
- **Controls** are every other final prospectus linked on the same merchant banker's own website (Ekadrisht Capital, `ekadrisht.com/past-ipo-filings`) at the time of selection, apart from the Trafiksol positive: **Aelea Commodities, Indian Emulsifier, TBI Corn**. Peshwa Wheat, Speciality Medicines and Raviraj Process Controls were left out only because the site links no final prospectus for them.
- Nothing was dropped after seeing results. No SEBI order against any of the three was known to me at selection time; I did not check afterwards to decide inclusion.
- **Flagged** means at least one signal with status "doesn't match".
- Each prospectus is scanned once in agent mode with the cutoff set to the date printed on its cover, with the code and ruleset (`RULESET_VERSION = 1`) as committed before the scans.
- Positive: Trafiksol ITS Technologies (SEBI interim order 2024-10-11, refund order 2024-12-03, final order 2026-08).

## Known confound
All four issues share one banker, so banker lines (BK-04/05) are nearly identical across cases and cannot separate them. Only vendor, site, litigation and news lines can.

### What run 1 showed (diagnosis of every flagged line, before any fix)
| Line | What it really was | Verdict on the line |
|---|---|---|
| Aelea VX-03 and VX-06 about "Krishna Enterprises" | The prospectus vendor is a firm with no company form in its name. The registry search matched an unrelated *Private Limited* of the same name (a Delhi company), and a court page for another Krishna Enterprises. | **Bug (namesake).** Same failure class as the earlier promoter mix-up. |
| TBI Corn LT-03 "2 matters naming the issuer" | The scan read the **lead manager** ("SWASTIKA INVESTMART LIMITED") as the issuer, because it was the first company listed on the cover. | **Bug (wrong issuer).** |
| TBI Corn VX-03, ARKA Sustainable Energy Solutions | A company incorporated in Nov 2023 with ₹1 lakh paid-up capital quotes ₹1.10 crore: 110 times, just over the 100x threshold fixed before any control was scanned. | **The rule worked as written.** Whether this is a real concern is not known; the control has no known SEBI action, so it counts as a flagged control. |
| Indian Emulsifier, 14 of 14 | One vendor, "Samarth Engineering", was also matched to a same-named company in another state (registry page West Bengal, Maps listing Pune) and reported as "checks out". | **Bug (namesake), this time false reassurance.** |

Other defects the controls exposed: issue-expense rows ("Total Estimated Issue Expenses", "Lead Manger Fees ...") read as vendors; one vendor repeated up to five times (a 65-line card); the section locator missing 4 of 7 sections in TBI Corn and one in Indian Emulsifier because of different chapter titles; one model call hung for 8 minutes with no timeout; an empty office address printed as "NIL, NIL" was searched on Maps.

None of these was fixed by changing a threshold or a rule's verdict. They are identity and parsing bugs, fixed in commits `23bc9a3` to `9635504` (`git log` has the details). The 100x threshold stayed as pre-registered.

Run 1 caveats: the Trafiksol row is the scan made earlier the same day with the cutoff set by hand to 2024-09-03 (same code for these rules). Indian Emulsifier was killed once by the hang and resumed from cache with identical code.

### Run 3 reading
- Testing on a document never seen before (Teamtech Formwork's red herring prospectus, downloaded from sebi.gov.in) exposed three extraction bugs, all fixed without touching a rule or threshold: the model wrapped names in its own citation tags (`<co>Name</co: 0:[59,62]>`), so grounding dropped them; PDF line breaks inside a vendor name made the query guard refuse a search and crash the scan; and Cohere answered one 17 KB section with a persistent 422, which is now retried in halves. A per-minute rate limit also used to retire a key for the whole scan; it is now waited out.
- The citation-tag fix changed one control. TBI Corn's lead manager is Swastika Investmart; in run 2 its name had been dropped by that bug, so the banker check ran on the next name, SS Corporate Securities. With the right banker, BK-04 reports a SEBI order naming **Swastika Investmart** dated Mar 2021. It is still a fact about the banker, not the company, and the card says so.
- Controls flagged: still 1 of 3, still TBI Corn, now for the correct banker. The other cards are unchanged apart from counts. Credits are lower-bounded by the cache: the table's last column is all runs on that scan id.
- Known weakness seen here: the lead-manager extractor can return more than one name (TBI shows three), and the banker check uses the first.
