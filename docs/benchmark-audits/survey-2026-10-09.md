## Method
- **Same rules.** Ruleset version 1, thresholds unchanged (the 100× vendor-capital screen, the 18-month balance-sheet limit and the rest). Evidence is read as of each prospectus date.
- **Mode.** `--mode fixed` with `--max-credits 18` per scan, because about 97 SerpApi credits remained. The controls in the earlier audit ran in agent mode. The investigator only gathers evidence and never changes a verdict, so fixed mode can leave more lines at "couldn't find" but shouldn't create flags.
- **Order and stopping.** Scans run in the table's order. If the credits run out, the remaining prospectuses are listed as not scanned.
- **What counts as flagged.** Any line that doesn't match. Each flag is then checked by hand against its source, and the reading says whether it is about the company, its vendor or its banker.
- **No ground truth.** None of these companies has a known problem, so this measures how often Quaoar flags ordinary companies, not accuracy.
