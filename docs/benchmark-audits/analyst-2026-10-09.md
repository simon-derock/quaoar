# Analyst agent evaluation, 2026-10-09

**What is measured.** Eight fixed questions per recorded case: one per check, "why was this flagged?", an advice question and an instruction-shaped one. A reply passes if it cites a card line of the check the question is about. The other passing replies are: the fixed reply for advice and injection questions; for a card with no line on that check, a plain "this card has no line about…"; and for "why was this flagged?", the line or lines that didn't match.

**Method.** `uv run python scripts/analyst_eval.py evidence` (no model, all five cases) and `uv run python scripts/analyst_eval.py agent trafiksol tbi-corn aelea` (Cohere `command-a-03-2025`, follow-up searches through SerpApi, at most 3 searches and 3 credits per question). Answers are recorded in the ledger; running the command again replays them with no model call.

**What the guards do, in order.**
1. Advice, "is it safe" and instruction-shaped questions get fixed replies without a model call.
2. A card where nothing failed to match answers "why was this flagged?" exactly, without a model.
3. Otherwise the model plans from the lines a retrieval step marks as related, reads lines for free, and may search.
4. Its answer is shown only if:
   - every cited line or result exists, whether cited in the field or named in prose ("line 6");
   - an uncited answer restates card lines closely enough to be traced to them;
   - every number in it appears in its sources;
   - the wording and advice guards pass.
5. Anything else falls back to the card-only answer.

**Development notes.** The first live run showed four problems, each fixed before these results:
- an arithmetic slip ("17,700 times" for 1,770), now caught by the number check;
- follow-up searches for a question the card already answered, now steered by the related-lines hint;
- Maps results that were found but not reported, now required by the prompt;
- correct answers with empty citation fields, now traced through prose mentions and attribution.
